# YBots (Android)

One Expo (SDK 58) codebase builds the YBots app (`com.yancey.cleftbot` unless `YBOTS_ANDROID_PACKAGE` is
set). See `app.config.ts`.

- Expo ships breaking changes every SDK release. Check the versioned docs
  (https://docs.expo.dev/versions/v58.0.0/) before touching an Expo or React Native API.
- Add packages at the versions in `node_modules/expo/bundledNativeModules.json`
  (`npx expo install <pkg>` does this when Expo's API is reachable).
- `android/` is generated by `npm run prebuild` and is not committed.
  Configure native behaviour in `app.config.ts` and config plugins only.
- Builds are made on the home build server with Gradle, not EAS.
- Navigation is a small screen stack in `App.tsx`; screens live in `src/screens/`.
- Bot characters come from the server's own shapes (`npm run shapes` regenerates `src/shapes.json`);
  icons come from `scripts/gen-icons.mjs`.
- The phone signs in with a bearer token from a QR sign-in link, kept in SecureStore. It answers
  approvals only with the card's digest. "Always allow" is offered where the card allows it (never for an email send).
- Run `npm run typecheck` before calling a change done.
- To see the screens without a phone, `npm run preview:web` renders every screen with demo data
  (`preview/Preview.tsx`, picked with `?screen=home|chat|computer|newbot|look|call|signin|welcome`,
  `&few=1` for a three-bot install). Compare against the Grok Bot references before calling a look done.
- Shared look pieces live in `src/components/ui.tsx` (round buttons, card buttons, sheets, grouped
  lists, chips, notices) and `src/theme.ts` (`color`, `type`). Use them rather than one-off styles.
- A bot's computer (`src/screens/Computer.tsx`) is noVNC in a WebView. The page is `vnc/page.js` +
  `vnc/page.css`, bundled by `scripts/build-vnc.mjs` into `src/vnc/page.generated.ts` (gitignored,
  rebuilt on `npm install` or `npm run vnc`). The app opens the screen socket itself (`src/screenLink.ts`,
  bearer token + Access headers) and passes bytes to the page; the page never reaches the network.
  The touch bar lives in the page so the phone keyboard opens from a real tap.
- Voice calls and dictation (`src/voice/`, `src/screens/Call.tsx`) use the local module `modules/cleft-voice`
  (Kotlin: AudioRecord on the voice-communication source for echo cancellation, AudioTrack for the bot's
  speech). The call logic mirrors `web/src/voice/call.ts`; keep the two in step. The server does all the
  speech work (`server/src/voice.ts`: /turn, /speak, /stt), so a new voice engine there needs no app change.
  Preview: `?screen=call` and `?screen=callerror`.
- Phone assistant (`src/assist.ts`, `src/components/AssistantSettings.tsx`): the app declares an `ASSIST` intent filter,
  which qualifies it for Android's assistant role (an "activity that performs assist actions",
  https://source.android.com/docs/core/permissions/android-roles). The person picks the app in Android's default
  digital assistant screen (apps can't request this role); the gesture then opens the chosen Bot's chat (Leonard,
  else the main Bot) and, with "Start listening" on, starts dictation. Native side: `Shared.kt` / `takeAssist` in
  `modules/cleft-background`. Web and Windows get the same through `web/src/lib/talk.ts` (`/?talk`, the Talk shortcut).

## Assistant card (modules/cleft-assist)

The phone's assistant gesture shows a card over whatever app is open (src/assist/AssistCard.tsx, the React
Native component `assist`, drawn by AssistActivity, a see-through ReactActivity in its own task). Android's
assistant role picks the app's VoiceInteractionService (AssistService); each press opens AssistSession, which
turns off its own window and calls startAssistantActivity. The screenshot Android hands over (only when the
person allows "Use screenshot") stays in the cache until Share screen is tapped. AssistRecognitionService only
passes speech requests on to the phone's own recognizer (Android makes an assistant name one). The card sends
by itself when you stop talking (src/voice/quickAsk.ts, the same file as web/src/voice/quickAsk.ts).
