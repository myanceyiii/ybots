# YBots for Android

`mobile/` is the Android app: one Expo (SDK 58, React Native 0.88) codebase. It has every bot, groups, approval cards, screens, voice calls and dictation, files, pages and
settings.

It talks only to your own YBots server. Nothing is built into the app: it learns your server's address
from the sign-in QR code.

## Install a released build

When a release has APKs attached (the repository's **Releases** page), download the one you want on the
phone and open it. Android asks once to allow installs from that browser or file manager. Released APKs
use the id `com.yancey.cleftbot`; a later release installs over
an earlier one.

## Build it yourself

You need Node.js 22.12+, JDK 17, and the Android SDK (command-line tools, platform tools, and the
platform and build tools Gradle asks for on the first run). On Linux:

```bash
cd mobile
npm ci
# Optional: your own application ids, so your build never collides with a released one
export YBOTS_ANDROID_PACKAGE=com.example.ybots
npx expo prebuild --platform android --clean
echo "sdk.dir=$HOME/Android/Sdk" > android/local.properties
cd android
./gradlew assembleRelease                          # add -PreactNativeArchitectures=arm64-v8a for a smaller, phone-only build
ls app/build/outputs/apk/release/app-release.apk
```

`android/` is generated by `expo prebuild` and is not committed; configure the app in `app.config.ts`
and the config plugins in `plugins/` and `modules/`.

**Signing.** The generated project signs release builds with the Android debug key
(`~/.android/debug.keystore`), which is fine for your own phones. Keep that key file: Android only
installs an update signed with the same key. To sign with a key of your own, make one with `keytool`
and add a `signingConfigs.release` block to `android/app/build.gradle` after `prebuild` (see the
[React Native signing guide](https://reactnative.dev/docs/signed-apk-android)).

**Versions.** Set `version` and `android.versionCode` in `app.config.ts` before each build you hand out.
A phone installs an update only when its `versionCode` is higher.

Install on a phone with a USB cable (`adb install -r app-release.apk`) or by copying the file over.

## Sign in

1. On a device that is already signed in (or with `bash scripts/sign-in-link.sh you@example.com` on the
   server), open the account menu and choose **Sign in another device**. It shows a QR code that works
   once, within 15 minutes.
2. Open the app and scan it (or paste the link). The phone keeps its sign-in in Android's secure storage.

The address must be `https://` (the app refuses plain http). On a Tailscale address the phone needs the
Tailscale app on. Behind Cloudflare Access, give each phone an Access service token
(`CF_ACCESS_PHONE_TOKENS`, see the README's "Signing in"), so codes made for that person carry it.

## What the phone adds

The same features as the web and Windows apps, plus what only a phone can do: notifications with
Allow/Deny on low-risk cards, quiet hours, an optional background service for long jobs, the share
sheet (share text or a link to a bot), app-icon shortcuts, a home-screen assistant gesture (pick YBots as
Android's default digital assistant), phone timers and alarms a bot can set after you allow it, voice
calls and live dictation. Details: [phone-actions.md](phone-actions.md), [voice.md](voice.md).
